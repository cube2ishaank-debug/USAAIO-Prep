## 📌 Repository Contents

The main notebook will cover the full spectrum of the USAAIO Round 1 scope, organized systematically using markdown sub-sections (`### Page / Question` format):

* **Linear Algebra Foundations:** Systems of equations, Gaussian elimination, row reduction, matrix operations, determinants, and vector space transformations.
* **Multivariable Calculus & Optimization:** Partial derivatives, vector gradients, multi-variable chain rule, and manual backpropagation derivations.
* **Machine Learning Theory & Scikit-Learn:** Classical models (Linear/Logistic Regression, Decision Trees, SVMs), model metrics, and feature normalization pipelines.
* **Deep Learning Mechanics & PyTorch:** Custom `nn.Modules`, autograd mechanics, tensor shape manipulation, and 2D Convolutional Neural Networks (CNNs).
